# NEESH Fragrance Chatbot Prototype

A small web prototype of a NEESH fragrance and brand guide. This source is part
of the project portfolio and can be run locally or deployed as a web service.
There is no live hosted demo yet.

This is an independent prototype, not an official NEESH product. Product facts,
prices, and availability are a snapshot and may become outdated. Check the
[official NEESH website](https://neeshperfumes.com) for current information.

## Run locally (optional)

### Requirements
- Python 3.9 or newer
- An Anthropic API key for your own use
- Internet access for the Anthropic API and the remote NEESH logo/font assets

For local development, provide your own Anthropic API key. Never commit your
`.env` file or paste an API key into source code.

### Start the development server

1. Clone or download this repository, then open a terminal in the project
   folder.
2. Create and activate a virtual environment:

   **Windows PowerShell**

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   **macOS / Linux**

   ```sh
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Install the dependencies:

   ```sh
   python -m pip install -r requirements.txt
   ```

4. Create a local `.env` file from the example:

   **Windows PowerShell**

   ```powershell
   Copy-Item .env.example .env
   ```

   **macOS / Linux**

   ```sh
   cp .env.example .env
   ```

5. Open `.env` and replace the placeholder with your own key:

   ```env
   ANTHROPIC_API_KEY=your_anthropic_api_key
   ```

   `CHAT_ACCESS_CODE` can be left blank for local-only use. Set a value if you
   want to test the protected demo gate locally.

6. Start the app:

   ```sh
   python app.py
   ```

7. Visit [http://localhost:5000](http://localhost:5000).

If port 5000 is already in use, stop the other local Flask instance or set the
`PORT` environment variable.

## Deploy the browser demo

GitHub stores the source code; GitHub Pages cannot run this Flask backend or
securely hold the Anthropic API key. The included `render.yaml` configures
Render to run the Flask app.

1. Create a [Render](https://render.com/) account and connect it to GitHub.
2. Create a new **Blueprint** from this repository and select
   `projects/neesh-scent-guide/render.yaml` as the Blueprint file.
3. In the service settings, set the **Root Directory** to
   `projects/neesh-scent-guide` if Render does not infer it from the Blueprint
   file location.
4. When prompted for environment values, enter:
   - `ANTHROPIC_API_KEY`: your own Anthropic API key. Store it only in Render's
     environment settings; never add it to GitHub.
   - `CHAT_ACCESS_CODE`: a private code of at least 10 characters to share only
     with people you want to let into the demo.
   - `FLASK_SECRET_KEY` is generated by the Render configuration.
5. After deployment, Render provides a public `*.onrender.com` URL. Send that
   link and the access code to your testers. They can use the chatbot in their
   browser without installing anything.

The app gates chat behind the shared access code and limits each IP to 5
requests per minute and 30 per day. These prototype limits are held in memory
and may reset when the service restarts; they are not a guarantee against API
charges. Set a usage/spend limit in your Anthropic account and only share the
URL and code with people you trust. Render's free web services may spin down
when idle, so the first request after inactivity can take longer.

## Prototype files

- `app.py` — Flask routes and Anthropic chat integration
- `public/index.html` — responsive chat interface
- `store_catalog.py` — fragrance note pyramids, listed prices, and snapshot
  availability
- `store_knowledge.py` — brand story and store-policy reference
- `.env.example` — safe API-key template
- `requirements.txt` — Python dependencies
- `render.yaml` — Render web-service deployment configuration

The app does not train or fine-tune a model. It sends the local catalog and
knowledge snapshot as context with each chat request. Local browser
conversation history is stored in that browser's local storage.
